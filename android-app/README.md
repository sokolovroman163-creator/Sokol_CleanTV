# Sokol_CleanTV для Android

Телефонное приложение для настройки Android TV / Google TV в одной локальной сети. Настройка основного пользователя ТВ (user 0). Android 8.0 и новее, без компьютера, root и ИИ. Интерфейс на русском: светлые полупрозрачные карточки, синие кнопки, вкладки «Телевизор», «Настройка», «Копии».

## Установка на телефон

Скачайте **Sokol_CleanTV-Android.apk** из Android-релиза репозитория. Откройте APK на телефоне и разрешите установку из используемого браузера или файлового менеджера. ZIP с исходниками не является установочным пакетом Android.

1. Подключите телефон и телевизор к одной домашней сети. Изолированная гостевая сеть не подойдёт.
2. Включите отладку на телевизоре. Нажмите «Найти телевизор в сети» или введите IP и порт. Поиск обнаруживает объявления ADB; некоторые прошивки их не публикуют.
3. Для обычной сетевой отладки порт обычно 5555. USB-отладка сама по себе не гарантирует доступ по сети. У ТВ должна быть возможность включить сетевое подключение.
4. Если ТВ предлагает беспроводную отладку по коду, нажмите «Подключить по коду с экрана ТВ». После сопряжения подключитесь к **порту подключения**, указанному на основном экране беспроводной отладки.
5. Подтвердите запрос с пульта. Приложение проверит систему, идентификатор, главный экран и список приложений.
6. Выберите нужные действия, просмотрите подтверждение и нажмите «Применить». Оставьте приложение открытым до завершения.
7. Проверьте на ТВ пульт, HDMI, звук, Wi-Fi и видео. После перезагрузки подключитесь снова и нажмите «Проверить после перезагрузки».
8. Завершите работу кнопкой отключения отладки. При открытом порте или неподтверждённом результате выключите отладку на ТВ вручную и отзовите разрешения.

## Возможности и ограничения

- Просмотр модели, версии Android, архитектуры и доступных действий. Каталог из публичных отчётов CleanYourTV — справочник, а не гарантия совместимости бренда.
- Отключение выбранных ненужных приложений для пользователя 0. Google Play, службы Google, входы, настройки, компоненты пульта, оборудования и неизвестные важные роли защищены. Неизвестная роль приложения блокирует отключение.
- Установка Sokol CleanTV Home с проверкой запуска и возвратом исходного Home при ошибке. Автозамена ограничена известными главными экранами Google TV, Android TV и Mi TV. На других можно использовать очистку и ByeByeDPI отдельно. На CVTE штатный Home остаётся включённым.
- Выбор JPG, PNG, WebP с телефона, до 20 МБ на изображение. Галерея на ТВ дополняется; стандартный фон сохраняется. Фон выбирается в настройках Sokol CleanTV Home на самом ТВ.
- ByeByeDPI 1.8.2 для ARMv7 / ARM64 устанавливается отдельной галочкой. Проверяется SHA-256 APK. Уже установленные версии Home и ByeByeDPI не обновляются, чтобы копия не обещала возврат старого APK. Первый запуск и разрешение VPN подтверждаются на ТВ. Кнопку в верхней панели предоставляет TV Home. Доступность YouTube зависит от сети и настроек ByeByeDPI; программа её не гарантирует. ByeByeDPI использует локальный VPN-интерфейс Android для обработки трафика, не предоставляет удалённый VPN-сервер.
- Не используются автоматические профили удаления по названию бренда, скрытые API Android, factory/test-экраны или обход подтверждения отладки.

## Резервные копии

Перед первой командой изменения создаются и проверяются копия и журнал. Сохраняются диагностические списки, состояния изменяемых приложений, исходный Home и, если он уже установлен, оформление и настройки Sokol CleanTV Home. Копия отмечается завершённой только после успешных запросов и записи контрольных сумм. Восстановление проверяет идентификатор устройства и отпечаток прошивки, затем возвращает исходные состояния 0–4 и Home. Новые APK остаются установленными, но отключаются.

**Это не резервная копия разделов прошивки или личных данных приложений.** Повреждение загрузчика и аппаратные неисправности этим способом не восстанавливаются. Записанные системные настройки используются для диагностики; программа не меняет и не восстанавливает их целиком. Восстановление не удаляет данные приложений.

Копии и ключ подключения находятся в закрытой папке приложения на телефоне, исключённой из облачного копирования. После удаления приложения копии пропадут. Подключение другого ТВ по тому же IP не позволяет использовать чужую копию. Старый вариант CleanYourTV Home без функции экспорта своих настроек блокирует изменения до обновления владельцем другим способом.

## Сборка из исходников на Windows

JDK 17, Android SDK Platform 35, Build Tools 35 и сетевой доступ к Google Maven, Maven Central, JitPack. Gradle 8.9 и AGP 8.7.3 закреплены. Если `JAVA_HOME` задан, сборка использует его.

Подготовьте родительский проект `bootstrap.ps1`. Соберите sibling-проект `launcher` в ASCII-папке командой `gradlew.bat assembleRelease` и поместите результат в `launcher/app/build/outputs/apk/release/app-release.apk`. Корневой `build.ps1` также готовит этот APK, но заодно собирает Windows-версию.

Запустите из PowerShell:

```powershell
.\android-app\build-android.ps1
```

Скрипт копирует подготовленный Home, проверяет/загружает закреплённые APK ByeByeDPI, формирует каталог, затем собирает приложение в ASCII-папке `%TEMP%\Sokol_CleanTV-android-build`, выполняет JVM-тесты и Android Lint. Итог — `android-app/Sokol_CleanTV-Android.apk` и SHA-256 рядом. Установочные бинарники, SDK, ключи, копии и рабочие файлы в Git не включаются. APK содержит необходимые установочные файлы и после установки не требует скачивания для настройки ТВ.

Отдельный ключ release-подписи создаётся в `work/android-phone/sokol-phone-release.p12`, случайный пароль — в `signing.password` рядом. Не публикуйте эти файлы. Сохраните их отдельно для выпуска обновлений: сборка с другим ключом не устанавливается поверх прежней.

Зависимости и лицензии: [THIRD_PARTY.md](THIRD_PARTY.md). Android-код находится в отдельной папке `android-app` и ветке `android-app`; Windows-версия сохранена.
