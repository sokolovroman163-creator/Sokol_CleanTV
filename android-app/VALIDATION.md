# Проверка Android 0.1.0

Проверено 12 ноября 2026 года.

- JVM: 21 тест, 0 ошибок. Локальный IPv4, защита Play/оборудования, роли Home/входов/пульта/VPN, состояния пакетов 0–4, идентификатор и прошивка, контрольные суммы копии, частичный сбой, восстановление исходного состояния Home, основной профиль, повторное подключение и проверка после перезагрузки.
- Android Lint: ошибок нет. Предупреждения о более новом target SDK, API библиотек и статической иллюстрации не означают проверки на физических устройствах.
- Эмулятор Android 16 API 36.1 x86_64: установка подписанного release APK, запуск и переходы между экранами. Проверены светлый интерфейс при системной тёмной теме, шрифт 140%, читаемость справки.
- Два инструментальных теста на собственном эмуляторе: RSA-разрешение ADB, shell и код ошибки команды, передача/чтение 100003 байтов через SYNC с проверкой SHA-256, отказ выполнять настройку на устройстве без TV-возможностей; тайм-аут TLS-сопряжения с узлом, который не отвечает.
- APK подписан отдельным RSA-ключом Sokol_CleanTV. `apksigner verify` и `zipalign -c -P 16 4` проходят. ELF-сегменты ARM64 и x86_64 Conscrypt и SPAKE2 имеют выравнивание 16384.
- Конфиденциальные ключи, настройки авторизации, резервные копии телевизоров и рабочие каталоги не входят в репозиторий или телефонный APK.

## Ещё не проверено на физическом оборудовании

Полный сценарий с настоящим телевизором: смена Home, отключение приложений, загрузка обоев, установка ByeByeDPI и откат. Они реализованы; проверки логики используют тестовый транспорт, реальный ADB/SYNC проверен отдельно на эмуляторе. Не проверены установка на Poco X8 Pro Max, настоящий шестизначный код сопряжения телевизора, проигрывание видео, HDMI, пульт и поведение конкретных прошивок после перезагрузки. Первая версия публикуется как prerelease.

Ручная проверка на ТВ: подключиться → сохранить копию → выбрать небольшую группу приложений → применить → проверить кнопки/HDMI/Wi-Fi/видео → перезагрузить с пульта → подключиться и проверить → восстановить копию и проверить снова → выключить отладку. Копия не является образом прошивки или копией пользовательских данных.
