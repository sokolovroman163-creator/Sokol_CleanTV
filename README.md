# Sokol_CleanTV

Приложение для Windows 10/11 x64. Настройка телевизоров Android TV и Google TV через ADB в локальной сети, без ИИ.

## Скачать

Готовая переносимая версия и небольшое обновление доступны в [Releases](https://github.com/sokolovroman163-creator/Sokol_CleanTV/releases/latest). Для первого запуска скачайте архив `Sokol_CleanTV-0.1.1-win-x64.zip` и распакуйте его целиком. Архив с окончанием `update.zip` предназначен для обновления уже установленной версии.

Распакуйте всю папку приложения и запустите `Sokol_CleanTV.exe`. Python, Android Studio и Java на ноутбуке пользователя не требуются. На телевизоре потребуется включить отладку и разрешить доступ с пульта. Для Wireless debugging предусмотрено сопряжение по коду.

## Работа с телевизором

1. Вкладка «Телевизор». Найдите устройство или введите его локальный IPv4-адрес. Нажмите «Проверить ТВ».
2. При необходимости сохраните копию кнопкой «Сохранить копию сейчас». Перед применением изменений программа всё равно создаёт новую отдельную копию.
3. На вкладке «Настройка» отметьте необязательные приложения для отключения, установку главного экрана и, по желанию, ByeByeDPI. Системные роли проверяются повторно перед отключением. Пакеты Android, ввод, HDMI и службы оборудования защищены. Файлы прошивки не изменяются.
4. Добавьте изображения JPG, PNG или WebP. В телевизоре выбор доступен при долгом нажатии OK на верхней кнопке «Настройки», затем «Настройки главного экрана → Обои». «Нет» возвращает стандартный фон.
5. Проверьте пульт, HDMI и воспроизведение на самом ТВ. Из вкладки «Резервные копии» можно перезагрузить телевизор. После загрузки подключитесь снова и нажмите «Проверить после загрузки».
6. Завершите работу кнопкой «Завершить и закрыть ADB». Затем отзовите разрешения отладки на самом телевизоре. Для Wireless debugging выключите её переключатель на ТВ.

Каталог показывает оригинальные отчёты CleanYourTV по брендам и моделям. Профили из каталога автоматически не применяются к похожему названию модели. Проверки конкретного устройства выполняются после подключения.

## Резервные копии и восстановление

Копии хранятся в `%LOCALAPPDATA%/Sokol_CleanTV/backups`. Папку отдельной копии можно перенести на другой компьютер и открыть через «Копия из другой папки…». Храните её целиком. В ней могут быть сведения об устройстве и сети.

В копии сохраняются системные настройки, списки пакетов, исходный Home, исходные состояния затронутых приложений и журнал действий. При откате восстанавливаются исходный Home и состояния изменённых приложений. Установленные программой новые APK отключаются и сохраняются на телевизоре. Приложения, которые были отключены до вмешательства, остаются отключёнными.

Это копия состояния настройки, а не образ разделов прошивки. Для восстановления нужны загружающаяся Android-система и рабочее подключение ADB. Личные данные сторонних приложений в неё не входят. Повреждённая прошивка или отказ загрузки требуют средств восстановления производителя.

Первый выпуск ориентирован на телевизоры со штатным Home. Если на ТВ уже стоит другой вариант CleanYourTV без функции экспорта параметров, программа остановит изменения, чтобы сохранить его оформление. Главный экран из этого проекта поддерживает экспорт и возврат собственных настроек.

## ByeByeDPI

Установка включается отдельной галочкой. В комплекте официальный подписанный APK для ARMv7 и ARM64. Требуется подтверждение VPN-разрешения с пульта. Рабочая стратегия зависит от сети. Верхняя кнопка VPN в главном экране управляет переключателем ByeByeDPI после первоначальной настройки. Для других VPN-приложений она открывает соответствующее приложение.

## Исходники и сборка

`sokol_cleantv/` содержит интерфейс и логику приложения. `launcher/` — воспроизводимый форк главного экрана с переключателем ByeByeDPI и экспортом настроек. `vendor/cleanyourtv/` содержит исходные инструменты и каталог CleanYourTV с их защитными проверками. Программа использует PowerShell, входящий в Windows.

Для разработки нужна среда Python из `requirements.txt`. Для сборки Android APK нужны JDK 17 и Android SDK 34. `build.ps1` выполняет тесты и lint лаунчера, затем собирает переносимую папку Windows-приложения. Папка `work/runtime` содержит встроенный Python 3.13 и зависимости. Команда `build.ps1 -SkipLauncherBuild` упаковывает уже собранный APK.

После клонирования исходников подготовьте зависимости. Нужны Git, установленный Python с командой `py`, JDK 17 и Android SDK с Platform Tools, платформой 34 и Build Tools 35.0.0. Скрипт использует закреплённую версию CleanYourTV и проверяет подписи APK ByeByeDPI.

```powershell
git clone https://github.com/sokolovroman163-creator/Sokol_CleanTV.git
cd Sokol_CleanTV
.\bootstrap.ps1
.\build.ps1
```

`launcher/` уже содержит изменения Sokol_CleanTV. Повторно выполнять `launcher-patch.py` или `prepare.ps1` после клонирования не требуется. Готовое приложение появится в `dist/Sokol_CleanTV/`. Кеши, ключ сборки, резервные копии и двоичные зависимости хранятся локально.

Проверка автоматическими тестами выполняется командой `python -m unittest discover -s tests -v`. Предпросмотр интерфейса без подключения к ТВ — `python app.py --screenshot work/preview`. Тесты используют поддельный ADB и не меняют телевизоры.


## Android-версия

Телефонное приложение находится в папке [android-app](android-app/README.md) отдельной ветки `android-app`. Для установки на телефон используйте APK из [Android-релиза](https://github.com/sokolovroman163-creator/Sokol_CleanTV/releases/tag/android-v0.1.0). Windows-версия и её релизы сохраняются отдельно.
