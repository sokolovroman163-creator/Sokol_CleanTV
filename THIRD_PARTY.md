# Компоненты

- CleanYourTV — https://github.com/Gathin23/cleanyourtv, MIT. Оригинальная лицензия находится в vendor/cleanyourtv/LICENSE. Исходные защитные проверки tools/*.ps1 сохранены.
- ByeByeDPI 1.8.2 — https://github.com/romanvht/ByeByeDPI/tree/v.1.8.2, GPL-3.0. APK из официального GitHub Release. Соответствующие исходники доступны по указанному тегу, лицензия включена в resources.
- Python — https://www.python.org/, PSF License. Лицензия включена во встроенную среду.
- PySide6 / Qt — https://doc.qt.io/qtforpython-6/licenses.html. LGPLv3/GPLv3 и лицензии включённых компонентов. Модули используются динамически и могут быть заменены в vendor/cleanyourtv/tools/venv/Scripts/site-packages. Лицензионные файлы находятся рядом с пакетами.
- Android Platform Tools — https://developer.android.com/tools/releases/platform-tools. Уведомления и условия находятся в vendor/platform-tools/NOTICE.txt.
